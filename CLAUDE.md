# Academic Homepage

Jekyll-based academic homepage using [luost26/academic-homepage](https://github.com/luost26/academic-homepage) template.

## Quick Start

```bash
bundle exec jekyll serve
# Site runs at http://localhost:4000
```

## Structure

- `_data/profile.yml` — Personal info, education, experience
- `_data/display.yml` — Homepage display settings
- `_data/navigation.yml` — Navigation menu
- `_data/authors.yml` — Author highlighting
- `_showcase/` — Project cards (grouped by subdirectory)
- `_publications/` — Publications
- `_news/` — News items
- `_posts/` — Blog posts
