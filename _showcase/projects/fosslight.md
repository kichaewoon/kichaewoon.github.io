## Overview

오픈소스 모델·데이터셋의 라이선스를 자동 분석하는 CLI 도구입니다. Hugging Face/GitHub URL 입력만으로 의존성을 재귀적으로 탐색하고 라이선스를 자동 분석합니다.

## Results

- **Accuracy 95.24%**, **F1 97.56%**

## Features

- Hugging Face/GitHub URL 기반 자동 의존성 탐색
- 재귀적 라이선스 분석
- LLM 활용 라이선스 판별
