## Overview

대학생 개발자가 프로젝트 정보를 입력하면 LLM이 포트폴리오를 자동 생성해주는 웹 플랫폼입니다. Fine-tuning과 RAG를 이용한 고도화를 진행 중입니다.

## Features

- 프로젝트 정보 입력 기반 포트폴리오 자동 생성
- LLM (Llama 3.1) 활용 텍스트 생성
- LoRA를 이용한 Fine-tuning
- RAG 기반 고도화
