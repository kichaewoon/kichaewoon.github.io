Personalized Web Agent

DAVIAN Lab, KAIST AI 2025.11 - Present
LLM/Agent Research In Progress
Python, LLM API (GPT-4o), Embedding Model, Clustering, Playwright

Overview

사용자의 web 탐색 history로부터 preference를 추론해 personalized web task를 수행하는 web agent benchmark를 설계하고, 평가 데이터셋 구축 및 개선된 agent를 구현하는 연구 프로젝트입니다.

Research Focus

  • Web browsing history 기반 사용자 preference 추론
  • Personalized web task benchmark 설계
  • 평가 데이터셋 구축
  • 개선된 web agent 구현 및 평가
